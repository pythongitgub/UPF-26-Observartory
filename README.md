# UPF26 — Food Processing Evidence Observatory

[![SCC Nexus](https://sccnexus.co.uk/assets/brand/scc-nexus-wordmark.webp)](https://sccnexus.co.uk/)

This is the **public publication repository** for UPF26, an SCC Nexus evidence-first research project.

**Public site:** https://sccupf.github.io/observatory/

The research engine, protocol development, validation logic and working materials are maintained separately. This repository is intentionally a one-way publication surface: only material approved for public release is copied here.

## Publication boundary

The public repository may contain:

- the generated observatory website;
- publication/status metadata;
- public methodology summaries;
- public tables, graphs and update notes;
- GitHub Pages deployment configuration.

It must not contain private working data, credentials, reviewer-sensitive material, unpublished evidence packs or internal research records.
