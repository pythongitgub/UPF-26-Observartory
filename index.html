Food Processing Evidence Observatory · SCC Nexus

What disappears when one food label tries to explain everything?

UPF26 is an evidence-first, falsifiable research project testing whether a single ultra-processed-food category conceals material differences between packaged foods. It separates classification, composition, whole-food retention and realistic exposure rather than compressing them into one opaque score.

Methodological architecture

Evidence first. Interpretation last.

UPF26 keeps evidence capture, deterministic rule firing, classification and human review separate. Ambiguity does not get converted into a confidence percentage.

1 · Evidence & transcription

Source material and transcribed facts are retained explicitly so later judgements can be audited back to the product evidence.

2 · Deterministic classification

Versioned rules can emit NOVA 1–4, unresolved 3/4, rule conflict or insufficient evidence. Conflicting determinative rules fail closed.

3 · Blinded review

Two reviewers independently assess the same locked evidence and methodology. Neither sees the other result until both are locked.

Public observatory separated from private engine

The public GitHub repository is now a one-way publication surface. Private research code and working records remain in the source repository; only approved public output is mirrored there after validation.

Protocol, append-only schema, deterministic classification engine, blinded-review model, adversarial pilot registry, stop/go analysis, tests and CI were established.

Adversarial 20-case pilot specified
